# 📚 Operação Kinha — Central de Estudos

A **Operação Kinha** é uma plataforma de estudos desenvolvida para ajudar estudantes a organizar sua rotina, acompanhar seu desempenho e manter a consistência na preparação para concursos públicos.

O projeto reúne ferramentas de produtividade e acompanhamento em um só lugar, com uma interface simples e responsiva.

## ✨ Funcionalidades

- **Painel de estudos:** visão geral da rotina e do desempenho.
- **Cronômetro de estudos:** acompanhamento do tempo dedicado aos estudos.
- **Registro de questões:** anote a quantidade de questões respondidas e os acertos.
- **Acompanhamento de desempenho:** visualize indicadores de aproveitamento e evolução.
- **Revisão de conteúdos:** organize assuntos que precisam ser reforçados.
- **Frases motivacionais:** mensagens para incentivar a disciplina e a continuidade dos estudos.
- **Questões gratuitas do Gran:** acesso direto à plataforma externa de questões.
- **Autenticação de usuários:** cadastro e login integrados ao Supabase.
- **Controle de acesso:** suporte à aprovação de usuários.
- **Interface responsiva:** experiência adaptada para computadores e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase — autenticação e recursos de backend.
- Cloudflare Pages — hospedagem e publicação da aplicação.
- Git e GitHub — versionamento e gerenciamento do código-fonte.

## 🚀 Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/erikasouzag/operacao-kinha.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd operacao-kinha
   ```

3. Abra o arquivo `public/index.html` no navegador ou utilize um servidor local para executar a aplicação.

**Observação:** os recursos de autenticação e backend dependem da configuração correta do Supabase. Para testar essas funcionalidades, verifique as configurações necessárias no projeto.

## 🎯 Objetivo do projeto

Facilitar a organização dos estudos, incentivar a constância e permitir que o estudante acompanhe seu progresso ao longo da preparação para concursos públicos.

A Operação Kinha busca transformar pequenas sessões diárias de estudo em uma rotina mais organizada e consistente.
